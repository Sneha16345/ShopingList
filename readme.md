# 🛒 Shopping List Web App

A sleek and responsive shopping list application built with **HTML**, **CSS**, and **JavaScript**. This app uses the browser's **localStorage** to save your items, ensuring your list persists even after closing the tab.

---

## 🚀 Features

- ✅ Add new items to your shopping list
- ✏️ Edit existing items with a single click
- ❌ Remove individual items
- 🧹 Clear all items at once
- 🔍 Filter/search items in real-time
- 💾 Automatically saves your list using localStorage

---

## 🛠️ Built With

- **HTML5** – Markup and layout
- **CSS3** – Styling and layout responsiveness
- **JavaScript (Vanilla)** – Core functionality and logic
- **Font Awesome** – Icons for improved UI/UX
